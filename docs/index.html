◍ Soil Moisture Indicators
Runs entirely in your browser · no server, no install

Needs a timestamp column plus vwc (and precip for a few indicators). Sub-daily data are aggregated to daily means (VWC) and totals (precipitation).

Have profile storage (mm)? Divide it by the profile depth (mm) to get the depth-averaged vwc (m³/m³) before uploading.
