File format

A comma-separated file with a header row:

ColumnContentNeeded
timestampDate or date-time, e.g. 2015-06-01 or 2015-06-01 13:00Always
vwcVolumetric water content (m³/m³)Always
precipPrecipitation (mm)API, dry-down timescale, wetting events
 
timestamp,vwc,precip
2015-06-01,0.312,0.0
2015-06-02,0.305,12.4
2015-06-03,0.341,0.0
  • Sub-daily data are aggregated on load: VWC to the daily mean, precipitation to the daily total.
  • Missing values: leave the cell empty. Days without VWC stay missing; days without precipitation count as 0 mm.
  • Profile storage (mm)? Divide it by the profile depth (mm) to get the depth-averaged vwc (m³/m³) before uploading.
  • Seasonal indicators (anomaly, percentile, SSI, SMDI, drought category, flash drought, memory) need at least two years; the trend test needs three.

Your file is read in the browser and never leaves your computer. Example: Stillwater station CSV.
